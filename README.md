# Unit 4 Lab: Campground Explorer
## Overview
Campgrounds is an app to view the most recent campgrounds of the National Park Service 

## Required Features
The core requirements for this project is to allow a user to see a list of campground descriptions, with the campground name, description, and media photo. When they tap on a specific campground, it will navigate them to a details screen with the same information, along with the campground's latitude/longitude.

## 🎯 Goals
- [x] Work with nested JSON and the Kotlin Serialization library
- [x] Pass data between screens
- [x] Use Intents and Navigation from one screen to another

## Application Features
- [x] Campgrounds are displayed using the RecyclerView
- [x] Can navigate to the Campground Details screen
- [x] Campground images are downloaded and displayed using Glide
